# WILDTRACK COMMUNITY
Statički sajt (HTML/CSS/JS), bez build koraka.
Cloudflare Pages: Build command — prazno, Output directory — `/`.

Fotografije: assets/img/hero.webp i assets/img/night.webp. Logo: assets/img/logo.jpg.
TikTok link: promeni jednu konstantu TIKTOK_LINK u assets/js/main.js (i href u index.html).
Domen: zameni https://wildtrack-community.pages.dev/ u index.html, robots.txt i sitemap.xml.
Pravilnik: sekcija #zakon u index.html.
